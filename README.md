# XP BOT website

Product introduction at [xp-bot.cn](https://xp-bot.cn/), independently hosted on GitHub Pages. Static HTML, CSS and JavaScript; no build step, third-party scripts, analytics or credentials. Keep CNAME and .nojekyll. The existing personal website is separate.

The November 3 redesign follows the measured layout and interaction sequence of the [Apple product reference](https://www.apple.com.cn/macbook-pro/proled-xdr-display/): product-first hero, sticky local navigation, large highlight cards with dot/progress and pause controls, product exploration, and continuous scroll close-ups. All product content and imagery belong to the XP BOT presentation; no Apple product media is included.

The current site uses five redacted native-interface films: a workspace montage, task status and search, template rules and fixed-area preview, robot entry and draft input, and company/personal connection tabs. These clips do not show a newly executed business job. Full knowledge Q&A and robot configuration recordings remain pending. Earlier demo-* files are illustrative films retained from the previous revision and are no longer used by the page.

Five automation cases are derived from full session histories and the existing tagging skill: business monitoring, product mapping, new-product onboarding, material inspection and new-product applications. Each case has six stages, concrete deliverables and process-specific checks. After-sales is part of business monitoring; robot configuration and computer diagnosis are separate capabilities. Private-knowledge messaging covers source collection, preprocessing, vector indexing, retrieval and source review. Word/PDF/scans/video need the corresponding parsing, OCR or transcription tools before indexing. Quick-link notes have a dedicated deidentified illustration; no real destination is included in its text or markup.

Motion includes contained scroll framing, pointer perspective and layer parallax, surface reflection, horizontal drag/snap with bounded inertia, text entrances, feature-pill expansion, camera pan/zoom, case transitions and fullscreen image expansion. Motion respects reduced-motion settings. Video and carousel activity pause when appropriate.

## Availability

Installer preparation is in progress. No public installation package is available. The download control stays disabled until a real distributable package is verified. The current development environment is macOS 13.0+ on Apple Silicon. Windows has not been released.

## Product claims

The creator supplied typical manual times per run: monitoring 60 minutes, mapping 50 minutes, new-product flow 30 minutes, material inspection 180 minutes and tagging applications 30 minutes. These are manual-effort examples, not automated-run benchmarks or daily savings. Automatic execution, platform waits and user confirmation are distinguished. Company onboarding assumes existing authorization and quota; model and external service costs depend on the configured services. No company endpoints, private documents or credentials are published. Local jobs require the computer and relevant services to remain available.

XP BOT is an independent customization based on DeepSeek Harness, not an official DeepSeek product.
