账号、下载与反馈隐私说明 · 更新于 2026 年 11 月 8 日

账号

你可以为账号设置显示 ID 和头像。只有点击保存才会提交；头像会裁切压缩为 256×256 的 JPEG。资料保存在 XP BOT 的私有账号数据库中，登录客户端后用于恢复显示，也可随时更改或移除头像。原图文件不会上传。

注册登录由 Supabase 账号服务处理。使用邮箱注册时，服务处理你的邮箱和密码；使用第三方登录时，服务获取登录所需的账号标识及授权范围内的基本资料。我们不在反馈数据库中存储密码。

注册验证及密码重置邮件通过 Resend 发送。为完成投递，该邮件服务会处理收件邮箱地址、验证邮件内容和投递状态；不会取得你的账号密码、聊天记录、模型 API 密钥或知识库资料。

浏览器会保存维持登录所需的会话信息。点击“退出账号”可清除当前浏览器的登录状态。账号用于身份识别、客户端下载与更新、私密反馈及其处理状态，模型 API 权限和企业系统授权仍由你本人配置。

客户端连接与下载

从 XP BOT 发起登录后，在官网完成账号登录；已登录的浏览器可以选择当前账号继续。后台保存账号关联、操作系统类型、处理器架构、软件版本及连接时间，不采集硬件序列号。客户端连接有效期为 30 天，可以在官网“登录设备”中随时退出设备。连接凭据在本机通过系统加密保存，后台仅保存凭据摘要。

安装包须登录且完成邮箱验证后下载。后台发放 2 分钟内有效、单次兑换的下载票据。兑换后获得短期有效的安装包地址，该地址在有效期内可再次访问，请勿转发。后台保留账号、安装包和请求时间等用于资格校验与防止滥用的记录。下载服务读取私有安装包文件，不读取你的聊天、知识库、模型 API 密钥或业务系统登录信息。

反馈内容

只有你点击“确认提交”后，才会发送本次问题标题、描述、类型、所选截图以及确认记录。仅你和获授权的 XP BOT 管理员可以访问这条反馈。反馈会关联你的注册账号，管理员可查看你当前的显示 ID、注册邮箱和稳定的用户编号，用于识别、联系和跟进问题；这些信息不会向其他普通用户公开。附件使用私有存储，查看时生成短期有效的访问链接。管理员可以在对应反馈下回复处理结果或补充说明。回复内容和时间仅该反馈的提交人及获授权的管理员可见，不会向其他普通用户公开。

提交前会预览实际发送的文字，客户端会隐藏检测到的链接、令牌、密钥及本机路径。这项处理不能保证识别所有敏感内容，请你检查文字并遮挡截图中的姓名、业务数据、真实链接和密钥。截图会重新编码以移除嵌入的图片元数据，图像中的可见内容需要你自行脱敏。

基础诊断信息为可选项，仅包含软件版本、操作系统类型、处理器架构和明确的错误代码。我们不会为了反馈自动读取聊天记录、知识库文档、快链内容、模型 API 密钥、浏览历史或完整设备信息。

服务与存储

账号、反馈文字和截图使用所选 Supabase 项目托管，存储地点以实际项目区域为准。服务商可能为提供登录、网络访问及安全防护处理 IP 地址、请求信息和服务日志。提交前请确认所选内容适合发送到这项服务。

官网由 GitHub Pages 托管，账号和下载资格由 XP BOT 的 Supabase 服务处理。Mac 安装包存储在 Supabase 私有存储中，Windows 安装包存储在 GitHub 私有分发仓库中。登录验证后，下载服务会提供相应的短期文件地址；GitHub 在文件分发中会处理 IP 地址和下载请求信息，不会取得你的 XP BOT 密码、模型 API 密钥、聊天或知识库资料。自动检查更新只获取公开的版本目录，可在客户端关闭；已发布的新版本会显示提醒，下载安装由你主动点击，应用不会因提醒而重启。账号连接与下载需要向该服务验证账号凭据，工作资料不会随更新检查上传。

保存与删除

账号和反馈资料保留用于登录、问题跟进及产品改进。如需申请删除账号或反馈，请在“账号问题”类别中提交请求，管理员核验身份后处理。不要在请求中附带密码、身份证件或业务机密。
