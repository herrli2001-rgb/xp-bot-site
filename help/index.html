下载 Mac 版 下载 Windows 版

1. 选择你的电脑，下载和安装

先注册官网账号并完成邮箱验证，或登录已有账号，再选择对应的系统和芯片。Mac 与 Windows 使用同一个 XP BOT 账号。

Mac · Apple Silicon

  1. 适用于 macOS 14 或更新版本、M 系列芯片的 Mac。Intel Mac 暂未提供安装包。
  2. 在“下载与更新”选择 Mac，下载 Apple Silicon 版 ZIP。
  3. 解压后将 XP BOT.app 拖到“应用程序”，再打开。

Mac 内测包采用本地签名，尚未完成 Apple 公证。首次打开请先核对官网来源，再按 macOS 系统提示确认。

Windows · x64

  1. 安装器支持 Windows 10 22H2（19045）或更新版本，以及 Windows 11 的 Intel / AMD x64 电脑。Windows ARM64 暂未提供安装包。
  2. 在“下载与更新”选择 Windows x64，进入下载页面后点击“下载安装包”。可在浏览器下载列表中查看进度。
  3. 下载完成后运行 XP-BOT-v0.1-Windows-x64.exe，按安装向导完成安装并启动 XP BOT。

Windows 内测安装包尚未正式代码签名。请核对 xp-bot.cn 来源与页面列出的 SHA256；遇到系统提示时先确认文件来源。当前已完成 Windows 11 x64 本机安装与重装检查，其他电脑的兼容性继续在内测中完善。

2. 使用官网账号

客户端左下角头像菜单打开“我的账号”，点击登录后在官网完成登录，客户端会自动显示账号状态。已登录官网时，核对账号后点“继续登录 XP BOT”。

头像和显示 ID 可在“我的账号”中修改，先预览再保存；邮箱展示本人绑定账号。官网登录用于下载、个人资料、私密反馈和版本更新，模型调用使用你自行配置的 API。聊天、文件和知识库保存在各台电脑，当前不提供跨设备自动同步。

3. 接入聊天和生图模型

  1. 在头像菜单打开“API配置”，选择公司或个人线路。
  2. 选择模型并填写本人有权使用的 Key。公司线路需要相应网络、权限和额度；个人线路使用自己的服务商账号。
  3. 点击“测试连接”，通过后再“保存并进入”。修改线路、模型或 Key 后重新测试。

图片生成还需要独立的生图模型与权限。聊天测试通过不代表生图权限已经验证。不要把 API Key、密码或 Cookie 发到聊天里。

4. 使用干净的本机知识库

软件只预置 XP BOT 使用说明和各功能操作手册，包含文字检索模型与运行环境。安装包不携带开发者的聊天、个人文档、业务报表、浏览器状态或登录凭据。

图片语义检索模型首次启用时下载到本机，约 717 MB。向知识库助手说“准备图片检索模型”，助手会启动下载并查询进度。下载失败时可检查网络后重试；文字检索与已归档原图读取仍可使用。

导入自己的资料时，先提供来源并授权操作。外部文档服务需要本人登录和相应权限，缺失正文或附件时会先说明。资料与索引在本机管理；用于回答的片段会按你选择的模型线路处理。

5. 让助手引导配置

图片、知识库、机器人及 POP 大店的各流程都有自己的助手角色。进入后直接说需求；需要登录、店铺信息或工作文件时，助手会说明具体步骤。

网页任务先检查专用 Chrome 是否被其他任务使用，必要时使用独立浏览器并由本人登录。打开助手不会自动执行业务、修改商品或发送消息。对外发送和线上修改按你的具体授权执行。

6. 反馈与更新

“我的账号”下方可以手动检查新版，也可保留自动提醒。只有真实发布且适合这台电脑的新版本，才会显示左下角下载按钮。

更新提醒不会重启正在工作的任务。等任务完成后退出 XP BOT，Mac 下载后替换应用，Windows 下载后运行新版安装器覆盖安装。原有会话与本机资料仍保留；替换前可以自行备份重要成果。

遇到问题，在头像菜单选择“意见反馈”，通过自己的官网账号提交。请先移除截图中的密钥、凭据及无关个人信息。
